🌐 Héberger le slider

Les iframes cross-origin sont bloquées depuis file:// par tous les navigateurs modernes. Il suffit de servir ce fichier HTML depuis n'importe quel hôte HTTP/HTTPS.

Option 1 — GitHub Pages (gratuit, permanent)

1. Créez un repo GitHub (public ou privé)
2. Uploadez dashboard-slider.html → renommez en index.html
3. Repo Settings → Pages → Branch: main → Save
4. Votre URL : https://votrecompte.github.io/votre-repo/
Option 2 — Netlify Drop (gratuit, 30 secondes)

1. Allez sur netlify.com/drop
2. Glissez-déposez ce fichier HTML
3. Netlify vous donne une URL HTTPS instantanément
Option 3 — Serveur local (test rapide)

Dans le dossier contenant le fichier HTML, lancez :
python3 -m http.server 8080
Puis ouvrez http://localhost:8080/dashboard-slider.html
Pourquoi cette restriction ?
Depuis file://, l'origine est null. Les navigateurs bloquent les requêtes vers des domaines externes (comme votre Metabase Railway) pour des raisons de sécurité. Une fois sur HTTP/HTTPS, les iframes Metabase /public/dashboard/… se chargent normalement car Metabase retire le header X-Frame-Options sur ses routes publiques.
